Mono Max — the Mono family with the volume turned up: each system shows its own
logo across the carousel instead of its name, on the same black ground with the
same off-white capsule. The logo is tinted to the row colour, so it reads
off-white on black and inverts to black on the selected pill, exactly as the
names do in Mono Dark.

Systems with no logo in `system/` fall back to their name, styled as Mono Dark
styles it — so an unrecognised folder still looks deliberate rather than blank.

Gamelist, menu, keyboard and screensaver are Mono Dark's.
